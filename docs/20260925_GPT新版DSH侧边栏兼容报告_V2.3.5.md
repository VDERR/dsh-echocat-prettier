# EchoCat Prettier V2.3.5 新版 DSH 侧边栏兼容报告

## 问题

DSH `v0.1.7-rc.2` 更新后的折叠侧边栏，为 `sidebar.footer.action` 中的插件入口提供 36×36 像素空间。旧版 EchoCat Prettier 在这个空间内仍同时渲染设置入口和 32 像素开关，导致按钮横向溢出、偏移或覆盖邻近控件。

## 修复

- 折叠状态只保留一个 36×36 的 `Aa` 设置按钮。
- 用按钮右下角状态点表示美化是否启用：绿色为开启，灰色为关闭。
- 展开状态继续显示“回复美化”文字入口和独立开关。
- 保留 `sidebar.footer.action` 官方插槽，不依赖宿主私有 DOM 定位。
- 未修改 AI 提示词、模型参数、回答文字、表情包匹配或长回复保护逻辑。

## 自动验收

- 折叠容器：36×36。
- 折叠按钮：36×36。
- 折叠状态开关数量：0。
- 展开状态开关数量：1。
- 折叠容器横向溢出：0。
- 单元测试、浏览器宿主测试、最终兼容测试和长回复压力测试均要求零错误。

## 实机边界

报告证明打包代码符合新版侧栏尺寸和官方插槽结构；真实 DSH Desktop 的安装、重启和视觉验收仍由用户完成。
