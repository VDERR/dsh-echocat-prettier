# EchoCat Prettier V2.3.4 安装、更新、卸载与验收

## 安装

1. 先退出 DSH Desktop。
2. 在 DSH 插件安装流程中选择 `20260924_GPTEchoCat回复美化插件安装包_V2.3.4.zip`，或者执行：

   ```bash
   dsh plugin --profile web add github:VDERR/dsh-echocat-prettier
   ```

3. 重新启动 DSH Desktop。
4. 在左侧栏底部打开“回复美化”，确认设置页顶部显示 EchoCat LOGO，诊断信息显示内部版本 `0.23.4`。

## 更新与仓库入口

- 设置页右上角的“检查更新”读取 GitHub 最新 Release，不会上传设置或聊天内容。
- 发现新版本时，按钮会显示远端版本号，再次点击会打开对应 Release。
- GitHub API 不可用时，按钮会改为“打开更新页”。
- GitHub 按钮固定打开 `https://github.com/VDERR/dsh-echocat-prettier`。

## 重点验收

1. 缩放 DSH 窗口，确认 LOGO、更新按钮、GitHub 按钮、关闭按钮和底部保存区始终可见。
2. 让 AI 连续输出一篇包含大量标题、列表、代码块和表格的长回答。
3. 生成过程中正文应保持稳定单列，不应随每个 token 反复闪烁或卡片跳位。
4. 特别长的回答会自动使用性能保护；主题颜色和基础层级仍保留，持续动画与复杂跨栏会暂停。
5. 滚动到回答末尾，确认最后一段、代码块和表格内容均存在。
6. 关闭“回复美化”，确认 AI 原文仍完整，复制内容不含插件装饰。

## 卸载

在 DSH 插件管理中停用并移除 `dsh-echocat-prettier`，随后重启 DSH。插件不修改历史回答数据；移除后只是不再注入展示样式和辅助图片。

## 验证边界

安装包完成隔离构建、内容校验、单元测试和 Chromium 宿主结构模拟。开发电脑没有安装或改动正式 DSH，最终兼容性以实际 DSH Desktop 环境为准。
