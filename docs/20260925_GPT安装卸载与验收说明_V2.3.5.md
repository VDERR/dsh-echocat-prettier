# EchoCat Prettier V2.3.5 安装、更新、卸载与验收

## 安装或升级

1. 先退出 DSH Desktop。
2. 在 DSH 插件安装流程中选择 `20260925_GPTEchoCat回复美化插件安装包_V2.3.5.zip`，或者执行：

   ```bash
   dsh plugin --profile web add dsh-echocat-prettier@0.23.5
   ```

3. 重新启动 DSH Desktop。
4. 展开左侧栏时，确认底部显示“回复美化”文字入口与独立开关。
5. 折叠左侧栏时，确认只显示一个居中的 `Aa` 按钮；右下角绿点表示已启用，灰点表示已关闭。
6. 打开设置页，确认诊断信息显示内部版本 `0.23.5`。

## 验收重点

- 展开侧栏：入口和开关均在侧栏范围内，不覆盖 DSH 原生按钮。
- 折叠侧栏：按钮严格为 36×36 像素，无横向溢出、错位或第二个开关。
- 缩放窗口：设置页关闭按钮、更新按钮、GitHub 按钮和底部保存按钮仍可见。
- AI 回复：文字、顺序、结论、复制内容与未安装插件时一致。
- 长回复：不闪烁、不丢字，并自动降低持续动画负担。

## 卸载

```bash
dsh plugin --profile web remove dsh-echocat-prettier
```

卸载后重启 DSH Desktop。插件设置保存在本机浏览器存储中；如需彻底清理，可在 DSH 的站点数据中删除 EchoCat Prettier 对应的本地设置。

## 验证边界

本版本已通过离线宿主模拟、36×36 侧栏几何检查、完整单元测试、长回复和多轮表情包测试。安装和真实 DSH 界面验收由用户自行完成。
