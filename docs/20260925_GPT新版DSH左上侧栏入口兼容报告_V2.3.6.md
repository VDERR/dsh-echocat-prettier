# EchoCat Prettier V2.3.6 新版 DSH 左上侧栏入口兼容报告

## 问题

DSH `v0.1.7-rc.2` 更新后，插件入口继续放在 `sidebar.footer.action` 会与底部模型管理、账号和窗口收缩状态竞争空间。即使限制为 36×36，位置仍不符合这次验收要求。

## 修复

- 改用官方 `sidebar.panellist` 上方面板列表。
- 入口顺序设为 `20`：位于 DSH 原生“插件”和“技能调用报告”之后、“工作区”之前。
- 图标由 DSH 宿主按钮承载，插件只提供 16 像素 `Aa` 图标和“回复美化”标签。
- 注册同键 `main` 面板，满足 DSH 面板导航约束。
- 设置弹窗挂载到 `shell.overlay`；面板桥接触发弹窗后立即返回当前会话，不留下空白主面板。
- 删除原 `sidebar.footer.action`、底部开关、折叠状态点和相关冗余样式。
- 未修改 AI 提示词、模型参数、回答文字、表情包匹配或长回复保护逻辑。

## 自动验收

- 上方侧栏入口行高：36 像素。
- `Aa` 图标：16×16 像素。
- 入口在工作区标题之前。
- `sidebar.panellist.id` 与 `main.key` 均为 `echocat-prettier-settings`。
- 设置层 ID 为 `echocat-prettier-settings-dialog`。
- 旧底部按钮、独立开关和折叠状态点数量为 0。
- 单元测试、浏览器宿主测试、最终兼容测试和长回复压力测试均要求零错误。

## 实机边界

报告证明打包代码符合新版 DSH 官方插槽结构；真实 DSH Desktop 的安装、重启和视觉验收仍由用户完成。
