# EchoCat Prettier V2.3.6 安装、更新、卸载与验收

## 安装或升级

1. 先退出 DSH Desktop。
2. 在 DSH 插件安装流程中选择 `20260925_GPTEchoCat回复美化插件安装包_V2.3.6.zip`，或者执行：

   ```bash
   dsh plugin --profile web add dsh-echocat-prettier@0.23.6
   ```

3. 重新启动 DSH Desktop。
4. 展开左侧栏，确认“回复美化”位于“插件 / 技能调用报告”之后、“工作区”之前。
5. 点击“回复美化”，确认设置弹窗打开，而且关闭弹窗后仍停留在原会话。
6. 打开兼容性诊断，确认内部版本为 `0.23.6`。

## 验收重点

- 左上入口：不再出现在模型管理和账号附近的侧栏底部。
- 点击入口：不出现空白主页面，不改变当前会话。
- 缩放窗口：设置页关闭按钮、更新按钮、GitHub 按钮和底部保存按钮仍可见。
- AI 回复：文字、顺序、结论、复制内容与未安装插件时一致。
- 长回复：不闪烁、不丢字，并自动降低持续动画负担。

## 卸载

```bash
dsh plugin --profile web remove dsh-echocat-prettier
```

卸载后重启 DSH Desktop。插件设置保存在本机浏览器存储中；如需彻底清理，可在 DSH 的站点数据中删除 EchoCat Prettier 对应的本地设置。

## 验证边界

本版本已通过离线宿主模拟、官方上方面板插槽检查、完整单元测试、长回复和多轮表情包测试。安装和真实 DSH 界面验收由用户自行完成。
